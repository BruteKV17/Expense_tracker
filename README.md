# Expense Tracker Pro

A premium Expense Tracker and Financial Analytics Web Application built with Flask, Flask-SQLAlchemy, Flask-Login, Bootstrap 5, Chart.js, JavaScript, and SQLite.

## Features

- User registration and login
- Modern dashboard with analytics
- Add, edit, delete expenses
- Search, filter, sort, pagination
- Budget planner
- Pie, doughnut, bar, and line charts
- Profile and settings pages
- CSV export
- Print to PDF
- AI-style expense insights
- Responsive UI

## Setup

```bash
pip install -r requirements.txt
python app.py
```

Open:

```bash
http://127.0.0.1:5000
```
